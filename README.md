# Университетский информационный помощник на основе RAG

ИИ-помощник, отвечающий на вопросы на основе университетских документов.

## Цель

Помощник извлекает релевантную информацию из документов и генерирует ответы с помощью LLM.

## Планируемый стек технологий
- Python
- LLM API
- embeddings
- vector search
- FastAPI
- PostgreSQL/pgvector
- Docker
